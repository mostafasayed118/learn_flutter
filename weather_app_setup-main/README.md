> The original course scaffold that the [Weather App](../weather_app/) was built from — a bare Flutter skeleton with an empty state screen.

> ⚠️ **This is the starter/assignment version (pre-solution).** For the finished, fully-featured application see [`../weather_app/`](../weather_app/).

## What's Here

- Default Flutter project scaffold (`android/`, `ios/`, `web/`, ...)
- `lib/main.dart` — `WeatherApp` entry point
- `lib/views/home_view.dart` — stub home screen with a `NoWeatherBody` empty state
- `lib/widgets/no_weather_body.dart` / `weather_info_body.dart` — placeholder widgets
- `assets/images/` — placeholder asset folder

## Getting Started

```bash
cd weather_app_setup-main
flutter pub get
flutter run
```
